La Jolla Freedive Club · Operating System

Protect the working system. Clarify the journey.

LJFC already has email automations, PDF forms, internal education spaces, medical/demographic elicitation, gear collection, Stripe, Supabase, and admin views. The next move is not a rebuild. It is a safe state model that makes the existing machinery easier to operate.

01

Inquiry

Candidate submits course interest. Store in `course_inquiries`; confirm by email.

02

Qualification

Light check: course fit, age/minor, swim ability, cert, gear, medical review flag.

03

Date / quote

Joshua or assisted draft proposes dates, price, group-rate opportunities.

04

Payment link

Candidate can reserve. Seat not held yet.

05

Reserved seat

Stripe confirms deposit/full payment. Booking confirmed. Portal link issued.

06

Onboarding

Demographics, emergency contact, swim profile, goals, fears, theory preference.

07

Forms + prep

AIDA medical/liability, LJFC waiver, gear profile, prep-guide progress.

08

Ready

Readiness complete. Logistics reminders sent. Joshua receives course briefing.
